# Wireframe Prototype Rules

- Demo UIs are grayscale, low-fidelity, hand-drawn prototypes.
- Use `wired-elements` for interactive controls and cards; use styled native buttons for primary actions.
- Use Patrick Hand typography, a graph-paper background, white cards, and sketchy borders.
- Use inline monochrome SVG doodle icons; never use emoji as interface icons.
- Keep prototypes as dependency-light single-page applications with state-based view switching.
